# python_installer

Place the Python 3.12 Windows 64-bit installer here before running the CLI sandbox.

## Download

[Python 3.12.10 Windows installer (64-bit)](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)

Or browse to the release page and choose "Windows installer (64-bit)":
https://www.python.org/downloads/release/python-31210/

The file should be named: `python-3.12.10-amd64.exe`

## Notes

- This folder is listed in `.gitignore` - the installer binary is never committed
- The installer only needs to be downloaded once per machine
- The CLI sandbox launcher will detect it automatically on next run
