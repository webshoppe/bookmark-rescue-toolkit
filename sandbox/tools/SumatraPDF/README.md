# SumatraPDF

Place the SumatraPDF portable executable here before running `setup_tools.bat`.

## Download

SumatraPDF portable is a single self-contained executable - no zip to extract: 
https://www.sumatrapdfreader.org/download-free-pdf-viewer

Choose **"64-bit build"** under "Portable version":
```text
SumatraPDF-X.X.X-64.exe
```

## Placement

Rename the downloaded file to `SumatraPDF.exe` and place it here:
```text
C:\Bookmark_Rescue\tools\SumatraPDF\SumatraPDF.exe
```

One file, no extraction, no installation needed.

## Notes

- Single executable - not committed to the repo.
- No install or session reinstall needed.
