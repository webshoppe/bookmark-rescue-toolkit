# SumatraPDF - Setup and Usage Guide

## Download

SumatraPDF is available as a standalone portable executable:  
https://www.sumatrapdfreader.org/download-free-pdf-viewer

Choose "64-bit build" under "Portable version". The file will be named: `SumatraPDF-X.X.X-64.exe`

> **Note:**  
> SumatraPDF portable is a single self-contained `.exe` file - there is no zip to extract.

## Placement

Rename the downloaded file to `SumatraPDF.exe` and place it at:
```text
C:\Bookmark_Rescue\tools\SumatraPDF\SumatraPDF.exe
```

That is all - one file, no installation, no extraction needed.

## Supported Formats

SumatraPDF opens more than just PDFs:

| Format | Use case in sandbox |
|---|---|
| PDF | Any documentation or exported reports |
| HTML | Basic rendering (no CSS/JS - use Firefox for vault output) |
| ePub | eBook reference material |
| CBZ/CBR | Comic/image archives |

## Opening Files

Double-click any supported file, or drag it onto the SumatraPDF window.

## Notes

- SumatraPDF is intentionally minimal - it does not support JavaScript or complex CSS, so use Firefox for viewing the vault dashboard and beautifier output.
- Single executable, no install required, no session reinstall needed.
