# PeaZip

Place the PeaZip portable contents here before running `setup_tools.bat`.

## Download

PeaZip portable is available from the official site: 
https://peazip.github.io/

Choose the **portable** build for Windows 64-bit:
```text
peazip_portable-X.X.X.WIN64.zip
```

## Placement

Extract **all contents** of the zip directly into this folder:
```text
C:\Bookmark_Rescue\tools\PeaZip\
```

The folder should contain `peazip.exe` at the root - not nested in a subfolder.

## Notes

- Portable contents are not committed to the repo.
- Available immediately without running `setup_tools.bat`.
- Settings persist across sandbox sessions since this folder is host-backed.
