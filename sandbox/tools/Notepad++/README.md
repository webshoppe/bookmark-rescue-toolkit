# Notepad++

Place the Notepad++ portable contents here before running `setup_tools.bat`.

## Download

Notepad++ provides an official portable build: 
https://notepad-plus-plus.org/downloads/

Click the latest release and choose:
```text
npp.X.X.X.portable.x64.zip
```

## Placement

Extract **all contents** of the zip directly into this folder:
```text
C:\Bookmark_Rescue\tools\Notepad++\
```

The folder should contain `notepad++.exe` at the root - not nested in a subfolder.

## Notes

- Portable contents are not committed to the repo.
- No install or session reinstall needed.
- Settings persist across sandbox sessions since this folder is host-backed.
